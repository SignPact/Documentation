# Send for signature

After placing fields, completing the flow creates a signature request.

## Signers & fields

- Fields are grouped by signer (email + name)
- Each signer receives a tokened link to review/sign

## Recipient link

`/document/:id?token=<signatureToken>` authorizes limited actions without login. The backend validates token and enforces permissions.
