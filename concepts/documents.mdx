# Documents

Documents live in a repository with folders, search, and status tracking.

## Versions

- View and restore versions from the Document view

## Permissions

- Roles: view, edit, sign, share
- Manage access from the right panel in the Document view

## Public vs tokened

- Public view: `/view/:id` (read‑only)
- Tokened access: `/document/:id?token=...` (recipient review/sign, no login)
