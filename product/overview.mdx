# App Routes and Flows

This page orients you to app routes, protections, and core flows as implemented.

## Routes

- Public: `/`, `/workflow-demo`, `/roi-calculator`, `/problem-details`, `/waitlist`, `/join-workspace`, `/login`, `/login/credentials`, `/pricing`, `/plan-comparison`, `/privacy`, `/terms`, `/vision`, `/compliance`, `/docs`, `/signature-sent/:id`, `/view/:id`
- Auth required: `/dashboard`, `/preview/:id`, `/contacts`, `/settings`, `/redlining`, `/redlining/:documentId`
- Payment‑gated: `/new-document`, `/generation`
- Token allowed (recipients): `/document/:id?token=...`

## Core flows

- Dashboard: folders, search, filters, status, move/hide
- New Document: upload → place fields → assign signers → create request
- Document: view, version history, download with embedded signatures, access control
- Redlining: AI analysis → annotations → summary
- Contacts: CRUD and search
- Settings: profile, preferences, signature, onboarding reset, security, billing and seats
- Generation: datasets and available docs (payment‑gated)

## Permissions and tokens

- Bearer JWT is required for authenticated routes
- Signature token in query string authorizes limited recipient actions (no login)
